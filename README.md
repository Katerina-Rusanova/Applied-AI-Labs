# Project Data Analysis
_Illustrative demo only. The images are altered screenshots of an AI support tool, relabelled as a recipe. They contain no real data, and this is not a tested recipe._

Local AI-Assisted Analytics
The Report Lens Agent adds an (1) AI Analyst to every product report. It highlights the headline figures, details what drives them and summarises what matters most. Each run is compared with earlier runs, so (2) changes are easy to see, and (3) trends and forecasts show where the numbers are heading. The result is quicker, better-informed decisions, with the analysis already done. For example: adjusting the recipe, finding which ingredient swap changed the mixture, or acting on a trend before the next mix.

Technologies: C#, .NET, Blazor Server, DuckDB, FalkorDB, oMLX, local LLMs, Apache ECharts
