# Applied-AI-Labs
Portfolio of AI applied research and development projects


# AI Projects

**Improve operational efficiency.**

## AI Report Analysis

Ask questions about reports and see the answer straight away, with charts and tables. Save the views you like and come back to them at any time.

## AI User Assistant

An AI chat helper that knows which screen you're on and assists with it.

## AI Knowledge Search

One searchable library of help pages, support materials, guides and training videos. Ask a question and it points you to the up-to-date solution, with a link to the source so you can act straight away.

## Technologies

C#, .NET, Blazor Server, DuckDB, FalkorDB, oMLX, local LLMs, Apache ECharts, ffmpeg, WebVTT, Docker, xUnit, Playwright
